# OPO 商城用户使用与操作说明

> 本说明对应 iopo3.0 静态交互原型。页面中的商品、账户、OPoc、订单、支付和分润均为模拟数据，不会接收真实资金或创建真实交易。

## 如何打开

- 跨设备测试：<https://zhuanzhuan11.github.io/iopo3.0/>
- 打开后点击顶部“使用指南”；电脑也可从左侧导航进入。
- 手机布局下使用顶部“使用指南”按钮。语言切换可选简体中文、日语和英语；本指南正文当前以简体中文提供。

## 消费者操作

### 浏览商品和查看详情

1. 点击“商城”，进入商品列表。
2. 点击商品卡片或查看按钮，查看商品名称、介绍、展示价格和 OPoc 示例。
3. 点击“去结算”查看结算界面。

商品和价格是演示样例，不代表可购买的真实库存、售价或商家承诺。

### 体验结算界面

1. 核对结算弹窗中的商品及样例金额。
2. 可输入演示 OPoc 抵扣值。当前原型限制抵扣比例仅为界面示例，不代表正式积分规则。
3. 选择“确认收货后分佣”或“付款后立即分佣”，查看界面如何呈现两种选择。选择立即分佣在原型中仅改变提示文本。
4. 选择微信、支付宝或银行卡等模拟选项，再点击“模拟提交订单”。

**注意：**提交结果只是页面提示，不会创建服务器订单，不会发起支付、扣积分、分佣或结算。

## 会员操作

### 注册或登录演示账户

1. 点击“我的”。
2. 在会员入口中选“登录”或“注册会员”。
3. 按界面填写昵称、手机号或邮箱，并使用页面提供的演示验证码完成操作。
4. 不要填写真实密码、身份证件、银行卡信息或真实验证码。演示资料仅存于当前页面内存，刷新后会清除。

### 查看订单和积分

- “我的订单”：查看预置演示订单及详情。
- “我的积分”：查看演示积分余额。
- “积分明细”：查看正负积分的样例记录。
- “每日签到”“兑换区”“我的推广”：浏览相应的界面演示。

上述余额、订单、推荐关系、奖励和兑换都不是账户或交易记录，不可提现或用于真实消费。

## 商家及管理界面体验

### 会员快捷支付演示

1. 进入“会员快捷支付”。
2. 选择演示消费者会员并输入消费金额。
3. 查看余额门槛提示、可用模拟支付选项和分润预览。
4. 点击“登记演示消费”查看页面反馈。

该功能只添加当前页面会话中的演示记录；不会连接微信、支付宝、银行卡或会员真实账户，也不会向商家收款或转账。

### 管理后台演示

进入侧边栏“管理后台”，可切换概览、商品、订单、会员、积分、兑换、分润和设置标签。部分按钮会改变浏览器中的样例状态，刷新后不保证保留。这里不是商家后台，也不支持真实商品发布、商户资料审核、收款账户维护或资金结算。

## 正式商家入驻流程（上线前规划）

正式版需要开发独立的商家中心。建议流程如下：

1. 商家提交主体、联系人、经营地址、营业执照及所需行业许可。
2. 平台核验商家主体、经营范围、商品资质和实际控制人信息。
3. 商家签署平台服务及销售协议，确认服务费、发票、发货、退换货、退款、消费者投诉和争议处理责任。
4. 通过微信、支付宝及银行卡收单机构的正式商户审核，建立获批的商家子商户及结算账户。
5. 商家提交商品资料，平台审核通过后发布。
6. 订单与支付机构对账完成后，按支付机构批准的分账与结算方案向商家付款。

正式多商家平台应先取得支付机构对业务主体、商户进件、资金路径、分账、退款和结算周期的书面确认。不得将测试页面或普通平台对公账户视为已获准代收代付。结算账户变更应由支付机构核验并经平台复核；对账、退款、争议和审计流程需在正式后端实现。

## 常见问题

### 能在当前页面真实购买或付款吗？
不能。支付方式仅为界面演示，不会扣款、形成真实订单或执行退款。

### OPoc 是真实余额吗？能不能提现吗？
不是。当前 OPoc 数字及变化为样例展示，不能提现、转账或作为真实账户余额。

### 商家可以现在申请入驻并上传商品吗？
当前原型没有可提交并保存的真实商家入驻或商品上传流程。正式商家中心仍需开发和审核流程。

### 商家货款会自动进入指定账户吗？
不会。当前没有真实收款和结算通道。正式上线应由支付机构审核平台模式，并用获批的商家收款与分账方案完成结算。

### 为什么刷新后刚才的操作不见了？
原型多数状态只保存在浏览器页面内存中，没有连接数据库。刷新页面、关闭页面或更换设备后不会同步。

### 页面演示余额门槛或分润数字是正式规则吗？
不是。它们用于说明可能的界面流程，不构成正式支付、分润、结算或积分规则。正式规则需由经营、财务、支付机构及专业顾问确认后再实现。

### 手机上如何打开指南？
点击顶栏“使用指南”。桌面浏览器也可使用顶栏入口或左侧导航。

### 有问题可以在哪里反馈？
页面底部列出的社区链接可用于反馈原型体验。请勿在群组或公开页面发送密码、验证码、身份证件、银行卡资料或其他敏感信息。
