# 产品范围与边界

## 当前原型

此仓库用于展示商城浏览、下单、积分和会员快捷支付等界面流程。简体中文、日语、英语以及屏幕适配行为沿用当前已确认的原型实现。界面数据和操作结果仅供体验，不会写入服务端。

## 模拟状态

- OPoc、会员身份、余额、推荐关系、订单、支付及分润仅为演示数据。
- 快捷支付、商品结算、积分抵扣/销毁、分润预览均不执行真实资金或链上操作。
- 页面中的成交和结算选择用于展示交互，不构成真实交易规则或法律、财务承诺。
- 不将 ZC/USDT 功能接入本商城支付流程。

## 生产建设仍需单独完成

正式商城需要服务端、数据库、身份与权限、安全控制、正式支付机构接口、订单退款与对账、积分并发与不可透支控制、审计日志、备份恢复、监控告警、客服运营和适用的合规审查。GitHub Pages 只承载静态测试原型。

## 安全边界

仓库只放演示源码与不敏感文档。不得提交密码、密钥、验证码、服务器/数据库配置、真实用户或交易数据、包含凭据的截图。生产配置应由受控的密钥管理系统提供。
